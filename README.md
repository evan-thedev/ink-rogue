# Ink Rogue

A 2D roguelike adventure game playable in your browser. Choose your class, battle through procedurally-generated rooms, collect weapons, and unlock random skills as you level up.

**Play now:** [https://evan-thedev.github.io/ink-rogue/](https://evan-thedev.github.io/ink-rogue/)

## How to Play

### Choose Your Class
- **Wizard** - Frail but devastating with high-damage magic
- **Knight** - Sturdy defender with high HP and reliable melee
- **Fighter** - Balanced warrior with strong offense and defense
- **Rogue** - Swift assassin with high speed and evasion

### Controls
- **Movement:** WASD or Arrow Keys
- **Attack:** Spacebar
- **Use Skills:** Number keys 1-5
- **Mobile:** On-screen buttons for movement and attack

### Gameplay
- Battle through 5 rooms of increasingly difficult enemies
- Gain XP by defeating enemies and level up
- Choose from 3 random skills when you level up (each skill has a random element!)
- Collect weapon upgrades and health pickups scattered throughout rooms
- Survive to the end to claim victory

### Skills System
Every skill has a **random element** - either the skill effect varies each use (like random explosion radius or heal percentage), or you get a random selection of 3 skills to choose from when leveling up. Keep an eye on skill descriptions to understand their random properties!

## Stack

- **Vanilla HTML/CSS/JavaScript** - No frameworks, no build tools
- **Canvas API** - 2D rendering
- **GitHub Pages** - Static hosting from repository root

## Features

- 4 unique character classes with different stats and starting abilities
- 12+ unique skills with randomized effects
- 6+ weapon types with varying damage and range
- Procedural enemy spawning across 5 rooms
- XP and leveling system
- Health and weapon pickups
- Ink-on-paper aesthetic with Fable 5.1 design tokens
- Mobile-friendly with touch controls

## Development

This is a self-contained single-page application. To run locally:

1. Clone this repository
2. Open `index.html` in your browser
3. Play!

No build process or dependencies required.
